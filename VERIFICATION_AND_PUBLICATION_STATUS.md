# Verification and publication scope

**Scientific reproducibility:** Study 1 and Study 2 statistical result JSON files reproduce exactly. Study 3 sequential and controlled-history outputs reproduce all scientific fields when the regenerated `created_utc` metadata is excluded. The publication candidate includes the frozen input designs, parsed outcomes, and analysis programs needed for these checks.

**Benchmark validation:** Three anonymized votes per scenario for 77 scenarios; Fleiss' κ = 0.835760; 65 unanimous; 76 with a majority; 76 majorities agreeing with frozen gold. Reviewer credentials/independence/blinding are not independently established from the underlying reviewer choices.

**Data scope:** Analysis-ready outcomes and annotations, with no complete original raw model-provider envelope archive. Reproduction uses saved data and makes no external model API calls. Historical Linux file-path strings are retained in some provenance/freeze artifacts.

**Publication:** Permission to release reported by the project representative. The GitHub maintainer remains responsible for rights and privacy checks, and for confirming final public repository visibility and verification status. See `docs/PUBLICATION_CHECKLIST.md`.
